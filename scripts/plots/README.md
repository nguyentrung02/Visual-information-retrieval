# Visualizations

This directory contains the diagnostic plots and tables generated by
`scripts/plot_results.py` from the retrieval result files.

## Regenerate

```bash
python scripts/plot_results.py \
    --results scripts/results/gdz-text-local.json \
    --results scripts/results/gdz-image-clip-vit-large-patch14-trial-1.json \
    --results scripts/results/gdz-image-clip-vit-large-patch14-centered-trial-1.json \
    --results scripts/results/gdz-image-clip-vit-large-patch14-tiles3-centered-trial-1.json \
    --results scripts/results/gdz-image-v4-tiles-prompt-nocenter-trial-1.json \
    --precomputed scripts/results/method-comparison.json \
    --outdir scripts/plots
```

## Plot gallery

| File | Description |
|------|-------------|
| `recall_comparison.png` | Recall@K bar chart: all methods side-by-side |
| `clip_ablation.png` | CLIP variants showing effect of centering, tiling, prompt |
| `rank_dist.png` | Histogram of ground-truth rank positions |
| `complementarity.png` | BM25 vs CLIP success/failure overlap |

## Tables

| File | Description |
|------|-------------|
| `comparison_table.md` | Markdown table of Recall@K for all methods |

## Key takeaway

V4b (tiling + prompt, **no** centering) is the best CLIP configuration.
Mean-centering is **catastrophic** in every ablation (93.5% top-50 share,
R@1=0.00%). Tiling provides the biggest recall gain (~80 DPI per tile vs
27 DPI), and the prompt template further improves alignment.
