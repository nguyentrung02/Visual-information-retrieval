# Visualizations

This directory contains the diagnostic plots and tables generated by
`scripts/plot_results.py` from the retrieval result files.

## Regenerate

```bash
python scripts/plot_results.py \
    --results scripts/results/gdz-image-clip-vit-large-patch14-trial-1.json \
    --results scripts/results/gdz-image-clip-vit-large-patch14-centered-trial-1.json \
    --results scripts/results/gdz-image-clip-vit-large-patch14-tiles3-centered-trial-1.json \
    --results scripts/results/gdz-image-v4-tiles-prompt-nocenter-trial-1.json \
    --precomputed scripts/results/method-comparison.json \
    --outdir scripts/plots
```

## Plot gallery

| File | Description |
|------|-------------|
| `recall_bar.png` | Recall@K bar chart comparing BM25, CLIP V1, and CLIP V4b |
| `recall_comparison.png` | All 5 CLIP variants (V1–V4b) side-by-side at Recall@1/5/20/100 |
| `clip_ablation.png` | Ablation: each CLIP variant with config annotation |
| `rank_dist.png` | Rank distribution of the gold page across 180 queries (BM25 vs CLIP) |
| `query_latency.png` | Average query processing time per method |
| `success_heatmap.png` | Per-query success matrix at k=1/5/20/50 (RdYlGn colormap) |
| `complementarity.png` | BM25 vs CLIP success/failure overlap (Venn-style bar chart) |

## Tables

| File | Description |
|------|-------------|
| `comparison_table.md` | Markdown table of Recall@K, nDCG@10, and avg query time for all methods |

## Key takeaway

V4b (tiling + prompt, **no** centering) is the best CLIP configuration.
Mean-centering alone causes severe hubness collapse (93.5% top-50 share,
105 distinct pages out of 3 021) and drops Recall@1 to 0.00%.
